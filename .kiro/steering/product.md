# Product Overview

This is a Solar2D (formerly Corona SDK) game project built on a professional template architecture. Solar2D is a cross-platform 2D game engine using Lua that targets iOS, Android, and desktop platforms.

The template provides production-ready scaffolding with modular architecture, scene management via Composer, persistent data storage, and cross-platform compatibility. It's designed for mobile-first game development with portrait orientation (720x1280 base resolution) and letterbox scaling.

## Key Features

- Professional modular architecture with clear separation of concerns
- Object-oriented programming support via middleclass and stateful state machines
- Robust data persistence with sandbox mode for testing
- Comprehensive utility modules for common game development tasks
- Unit testing infrastructure with Busted and Solar2D mocks
- Cross-platform support (iOS, Android, Desktop)
- Memory-efficient design with object pooling and proper lifecycle management
